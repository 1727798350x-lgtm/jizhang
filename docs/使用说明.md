# 简明记账 · 使用说明

## 一、在手机上安装

1. 用手机浏览器（推荐 Edge / Chrome / 三星浏览器）打开
   **https://1727798350x-lgtm.github.io/jizhang/**
2. 等页面完全打开后，点浏览器菜单：
   - Chrome / Edge：「添加到主屏幕」或「安装应用」
   - 三星浏览器：菜单 →「添加页面到」→「主屏幕」
3. 桌面会出现「记账」图标，以后点它即可打开；断网也能打开
4. 如果菜单里没有「安装」，说明当前浏览器不支持 PWA 安装，
   可以直接把网址收藏，在线使用同样没问题

> 注意：微信、QQ 等 App 内置浏览器不能安装，请复制链接到系统浏览器打开。

## 二、记一笔

1. 在明细页点右下角蓝色「＋」
2. 顶部选择「支出」或「收入」
3. 用数字键盘输入金额（支持两位小数）
4. 点选一个分类
5. 需要的话点「账户 / 日期 / 备注」修改，默认是上次用的账户和今天
6. 点右上角「保存」

## 三、看账

- **明细**：点月份两侧的「‹ ›」切换月份；点某一条可以修改或删除
- **统计**：看当月分类占比、近 6 个月趋势；切换「支出 / 收入」查看对应分类

## 四、管理账户和分类

「设置」页面：

- 账户：可新增、改名、改图标、设置初始余额；不用了的账户可以「归档」
  （归档后不再出现在记账页，但历史记录保留，可随时恢复）
- 分类：支出 / 收入分类分开管理，可以自定义名称和 emoji

> 已经被账单使用的账户 / 分类不能删除，只能归档，这样历史账目不会乱。

## 五、备份与换手机

数据只存在当前手机浏览器里，**清除浏览器数据会导致记录丢失**。

- 备份：设置 →「导出备份」，会下载一个 JSON 文件（建议存到网盘或发给自己）
- 恢复：新手机装好后打开 App → 设置 →「导入备份」→ 选择之前导出的 JSON 文件
- 换手机、换浏览器前，务必先导出备份

## 六、常见问题

**问：桌面图标打开后是白屏？**
答：先联网打开一次，等页面加载完；如果还是白屏，把浏览器缓存清掉再试。

**问：账单会丢吗？**
答：只要不清除浏览器数据、不卸载浏览器，账单会一直保留。建议每月导出一次备份。

**问：能同步到电脑 / 多个手机吗？**
答：第一版是纯本地存储，不支持自动同步。可以通过「导出 / 导入」JSON 文件手动迁移。

**问：支持深色模式吗？**
答：支持。「设置 → 外观」可以选跟随系统、浅色或深色。
